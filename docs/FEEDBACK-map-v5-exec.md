### 每条一句理由（任务书 §3 原句照抄；有矛盾的注在括号里）

1. **a1 沈家**：从坝西侧下来，绕开河边那条田埂，再拐回院门。
2. **a1 磨坊**：磨坊是村里唯一有大车的地方，门口必须能掉头。
3. **a1 陆家**：从西南角斜插进院，最短的一条土路。（**实测是从东南侧进** —— 起坡列 84 > 门列 78。按数字执行，理由文字见 §5.2。）
4. **a2 沈家**：院子扩过之后，路改成先贴着院墙东侧上来，再横切进院。
5. **a2 磨坊**：同上，但车少了、场院缩了。
6. **a2 陆家**：1951 井台修整过，路改从**西侧**斜插进来避让。（任务书原文写「东侧 / 从东南入」，与 72＜78 矛盾，见 §5.2。）
7. **a3 沈家**：院子扩到路边，路只剩十格，一条斜线切进门。
8. **a3 磨坊**：1976 路面硬化，场院改成硬收边。
9. **a3 陆家**：1976 这块地垫平了，车能斜着开上去。

### 为什么这九条真的「不是同一个模板」

不是把 45° 阶梯改几个数字，而是九种不同的构造：

- **S 形 2 折点**（a1 沈家）：两次反向，先往西北扎 12 列，再回拐东北，最后竖直落进门 —— 三次换向，指纹 `(2, 14, 63.3°)`。
- **L 形**（a2 沈家）：竖直 17 行 → 横切 9 格 → 再竖直 4 行。含一段 0°（纯水平）—— 全九条唯一有水平段的一条。
- **场院三种尺寸**（磨坊三条）：a1 = 5 宽 × 4 行（cols 44..48，能掉头）、a2 = 4 宽 × 4 行且后撤 1 行（小一号）、a3 = 3 宽硬收口无场院（水泥）。
- **斜切三种角度**（陆家三条）：a1 56° 从东南、a2 49° 从西南（互为镜像）、a3 33° 从东南并拉到 96 列 —— 分别是「短」/「反向」/「最缓」。
- 折点数分布 **2 / 0 / 1 / 2 / 0 / 0 / 0 / 0 / 0**，不是九条同款。
