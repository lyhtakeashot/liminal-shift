## §2 游戏事实（照抄进文档，别自己编）

- 名字：《阈限迁移 / SHIFT》—— 五帧：1926 / 1951 / 1976 / 2001 / 2026。
- 核心玩法：**空间冻结、时间可动、位置不变**。你在同一块地上换年代，位置不动；能过去的地方由「这一年的地形与建筑」决定。
- 双轴：`Shift` 切「空间轴 / 时间轴」；时间轴上按前进/后退键推一帧。
- 起点：2026 年环岛路面（`data/frames.json` 的 `start_frame = a5_2026`，`start_pos = [2048,1864]`）。
- 证物：24 张卡 / 51 条观察（2026-11-26 实算）。`I` 开证物档案。
- 日记：《水簿》双人对账簿（E 在书旁翻开）。
- 归档表：`G` 打开结案归档表（**取决于线 A 是否已合并**，见 §5）。
- 世界尺寸 4800×3600；视觉 32px 一格；Godot 4。
