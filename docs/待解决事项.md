## §7 流程教训（这次畸形是怎么来的）

1. **「数据线改帧」与「叙事线改文本」不能并行分派。** A4 摆位时 `DECIDE-a4-a5-layout.md:8` 已经写明「story.md 改文本是唯一出路——该项总策划已拍板」，但**文本从没被改**，于是空间硬塞成了现在这样。下次凡涉及位置/尺度，**文本与帧数据必须同一批改**。
2. **执行线抛回来的球必须接住。** `FEEDBACK-a4-map-build-exec.md:114` 写着「方案乙的取舍请总策划确认」，我没回、A4 就带着未确认的取舍交付了。

4. **世界重构这种全局改动必须连带核对「相对关系」**：路南移 512px 时没人检查房子/井/树与路的相对位置，于是「井边」「路边」两条空间关系同时失效。
5. **写「预期条数」基线要按规则实算**，别按去重视图数（L5 的 39→58 教训）。
6. **只精确 `git add` 自己那批文件，绝不 `git add -A`**；工作区长期脏（美术线 12 张 `_ref/art/*.png` 的 M、`美术资产/` 一批用户自删的 D、大批未跟踪 `lab/_*`）。
