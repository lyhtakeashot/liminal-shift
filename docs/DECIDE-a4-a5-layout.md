## 4. 几何约束口径（写代码前必须知道的坑）

1. **`wings` 四个数是 `[x, y, w, h]`（格起点 + 宽高）**，不是 x1,y1,x2,y2。依据：`scripts/house_shape.gd:148-152`（`wx=int(w[0]); wy=int(w[1]); ww=int(w[2]); wh=int(w[3])`，interior 填 `range(wy+1,wy+wh-1)×range(wx+1,wx+ww-1)`）⇒ **墙 = interior 的四邻格**，wings 覆盖的碰撞范围 = (wx..wx+ww-1)×(wy..wy+wh-1) 全格。`lot` 是 `[x0,y0,x1,y1]` 且**含两端格**（`house_shape.gd:415-418` ⇒ 尺寸比 wings 大），`lot` 只用于判家具是否落在院内，**碰撞体一律用 wings**。
2. **circle 的字段名是 `radius`，不是 `r`**；`solid` 缺省会按 false 处理。
3. **老槐树冠上抬 `rad*0.7`**（`world_view.gd:420` 排序键 + `:589-600` 绘制），所以**判「压槐」必须用上抬后的圆**，不是原圆。
4. **道路必须按同帧比较**：A1/A2 是 26 块弯路 road rect，A3/A4/A5 是单块 `[0,1664,3200,64]` 直路。拿 A3 的直路去卡 A1 的房子会全错。
5. **跨帧房子重叠是正常的**（同一栋楼转用途：沈家宅→小学、周家老屋→玩具店、粮站→超市），所以**不能拿 A5 三栋当 A4 四栋的障碍**，只能拿「A4 帧内部四栋互不重叠」当硬约束。
6. **引擎级红线**（`world_view.gd:268-296` `_scene_bboxes()`）：竖路绝不能用 `road:true` 的 rect（会与主路 `Rect2.merge` 成十字外包矩形，整帧只贴一次路面），必须 `polygon` + `solid:false` + `label:"路"`；每帧只能有**一个** `label==""` 的 rect（并进 field bbox）；`label` 非空的 rect 在背景层被 `pass` 掉（`:230`）→ **静默不显示**。
7. **lot 底色重叠也要算 FAIL**：`_draw_house_base` 贴的是 `lot_rect`，不是 wings ⇒ 画出来的底色比碰撞体大，评估“压住某物”要用 wings，但评估“视觉压住”要用 lot。

## 6. 老槐遮井：渲染层最小改法草案（只出方案，本线不改 `world_view.gd`）

**根因**：`scripts/world_view.gd:415-421` 的 circle 分支一律 `sort_y = center.y + rad*0.7`；`_draw_prop()` `:589-600` 里含「槐」的 circle 先画树干、再把**树冠圆心上抬 `rad*0.7`** 后画圆，而**井平画不上抬**（`draw_circle(center, rad, c)`）。于是 A5 老槐 r=160 的上抬树冠圆心 (1296,864) 完全罩住井 (1360,848) r=48 ⇒ 遮挡率 100%；A3/A4 r=96 各遮挡 61.8%；A1/A2 因为槐小且用贴图分支（不上抬）才没遮挡。

**方案 A（已授权，最小改动）**——给「井/碑」这类**地面标记**固定优先级，让它们永远画在树冠之上：

- 改点 1：`scripts/world_view.gd:415-421`，circle 分支的 `sort_y` 由「一律 `center.y + rad*0.7`」改为**按 label 分优先级**：井/碑等地面标记取 `center.y - 1.0`（一个恒定远小的深度，等价「永远在所有树冠之前/之上」），槐仍取 `center.y + rad*0.7`。
- 改点 2（可选、更稳）：`scripts/world_view.gd:589-600` 里树冠上抬量从 `rad*0.7` 降到 `rad*0.45`，或在 `_draw_prop` 命中「槐」时**先画树再画井**（渲染顺序而非深度）。
- 影响面：
  - **A1–A3 观感**：A1/A2 遮挡率本已 0%，改后仍 0%（只是深度键变了，贴图分支不动）；A3 从 61.8% → 0%，A4 从 61.8% → 0%，A5 从 100% → 0%，**井在五帧都完整可见**（符合「井是钥匙物证，必须看得见」）。
  - **既有回归**：`_mdtest/sort_check.gd` 只覆盖 A1–A3 的 12 栋，断言「排序结果按 sort_y 递增」「家具/屋顶/玩家先后」——改 circle 的 sort_y **不触碰墙/家具/屋顶/玩家**的键，但若新键破坏了「全局 sort_y 递增」的断言（3e）需同步更新该断言；`_mdtest/greybox_check.gd` 只断言热点/卡点可解释性，与 sort_y 无关。
  - **不要**给 A4/A5 补场景贴图：`_mdtest/asset_draw_check.gd:216` 断言 `AssetDraw.scene_tex("a4_2001","river") == null`，补图会让该断言挂。
