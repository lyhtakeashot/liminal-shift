## 7. 本轮为什么可能不动引擎（**请执行方实测确认，不要当成已证结论**）

初判三项「装饰房穿帮」全部可以在**数据侧**解决：

1. **贴错底图**：`scripts/world_view.gd:668` 的 `FAMILY` 只登记 A1–A3 的 12 个 id
   （`lu_house/lu_a2/lu_a3`、`shen_a1/a2/a3`、`mill_a1/a2/a3`、`zhou_house/zhou_a2/zhou_a3`）。
   新 id `decor_lu/decor_zhou/decor_zheng/shen_a5` 查不到 ⇒ 自动走色块降级。
2. **冒假线索**：`scripts/frame_data.gd:66` 的 `HouseShape.hotspots()` 只取 `fd.get("clue", false)`
   的家具（`scripts/house_shape.gd:405`）。装饰房 `furniture: []`、`shen_a5` 家具 clue 全 false
   ⇒ 不生成线索，**不需要新增 `no_clue` 开关**。
3. **门洞可走进**：碰撞由 `grid_of()` 生成的 `solid_rects()` 决定，门格留空。
   克隆时把 `doors: []` 与 `gate: []` 清空即封死 ⇒ **不需要 decor 分支**。

> ⚠️ **第 3 条必须由执行方实测确认**：`doors=[]` 是否真能把周边墙连成闭合矩形。
> 若不是，就老老实实加 decor 分支，别硬凑「零引擎改动」。

**唯一需改引擎且不阻塞的一处**：`scripts/world_view.gd:262-264` 河贴图画布写死
`Rect2(Vector2.ZERO + offset, Vector2(3200, 416))`。A5 世界宽 4800，但 `AssetDraw.SCENE_FILES`
只有 `a1_1926/a2_1951/a3_1976` 三帧 ⇒ A5 的 `rtex == null` ⇒ 走 `draw_colored_polygon`，本轮不受影响。
**属「A5 河贴图一交付就会立刻踩」的潜伏 bug**，建议顺手改成按 polygon bbox 贴。
