探针实测（`%TEMP%\count_probe.gd`，跑完已删）：

```
AFTER_SWEEP cards=25 obs=54
  idx=0 diary=true cards=26 obs=55
  idx=1 diary=true cards=26 obs=56
  idx=2 diary=true cards=26 obs=57
```

`try_collect()` 按 key 建卡、**同一年代只入一次**（`RESULT_DUPLICATE`），所以三个年代各翻一次 = +1 卡 +3 观察，不是 +3 卡。
