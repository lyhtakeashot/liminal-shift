## 1. 一句话背景

游戏从纯俯视改成**伪 3D**：所有立体物按 `(x, y - 高度)` 绘制。所以每栋房子的外观图，
**画布高度要比占地高 16px**，多出的那一格加在**画布顶部**，是墙 + 屋顶立起来的高度。
宽度、文件名、目录、张数、画什么，**全部不变**。

## 2. 唯一要改的规格

| 项 | 现在（错） | 改成 |
|---|---|---|
| 外观 `base` / `roof` 画布 | `lot_w × lot_h` | `lot_w × (lot_h + 16)` 像素 |
| 格数表示 | `gw × gh` 格 | `gw × (gh + 1)` 格 |
| 锚点 | 底部中心 | **不变**，仍是底部中心 |
| 对齐 | 画布底边 = lot 底边 | **不变**，多出的 16px 在顶部 |
| `base` / `roof` 关系 | 同尺寸同锚点 | **同宽同高同锚点**（都是 `lot_h + 16`） |
| 废墟 `lu_a3` | 只有 `base` | 也 +16（残墙同样要立起来） |
| 家具层 `props` | 九档 1×1…3×3 | **不动**（本来就允许"高度多画一格"做朝向立面） |
| 场景层 `scene` | 按 frames.json 实测 | **不动** |

**为什么必须改**：不改的话，屋顶向上溢出画布的那 16px 会被裁掉一条。**不报错、只是少一条**，
交上去验收也看不出来，等游戏里一跑才发现 23 张 P0 外观全要重画。
