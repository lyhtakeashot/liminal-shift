### 3.1 【坑 1】河 polygon 必须用权威公式，不能用 `lab/_a5_v5.py` 的 `river_surface()`，也不能用本任务书旧版写的那个公式

**事实**：现行 `data/frames.json` 五帧的河是**同一份 103 点、x 0..3200、上沿 y ∈ {192,224,256,288,320,352,384,416}**。`lab/_a5_v5.py:60-63` 自己造的是**153 点、x 0..4800、上沿最大 192** —— **逐点相同 0/103，是两条完全不同的河**，而且它那套公式跟真实河也对不上（真实河首段 x0..256 是 y=256，那套算出 147→160）。照抄它 ⇒ market / shen_a5 会**压进河里**（用权威公式实测：market 房顶 225 压河 **30016 px²**；shen_a5 房顶 352 压河 **3040 px²**）。

**权威公式**（`_ref/houses/_design_v5.py:59-74` 的 `river_depth(x)`，实测能 100% 复现现行河；**照抄下面这段，别自己改写**）：

```
base = 5.5 + 1.5*sin(x/13 + 0.6) + 0.8*sin(x/5.3 + 2.1)
center = (38 + 55) * 0.5          # = 46.5，MILL_X0/MILL_X1 的中点
sigma  = 16.0
bay    = exp(-((x - center) / sigma) ** 2)      # 注意：先除再平方，没有 2！
g      = bay * 8.0                              # 磨坊高斯凹口
depth  = int(round(max(4, min(15, base + g)))) # clamp 4..15
RIVER_Y[x] = (depth + 1) * 32                  # 格 → 像素
```

> 🔴 **凹口项必须是 `exp(-((x - 46.5) / 16.0) ** 2)`（先除再平方）。**
> 写成 `exp(-((x - 46.5)**2) / (2*16**2))`（多了个 2）**是错的**：两种写法在 150 列里有 **65 列不同**，
> 对现行河逐点比对时错的那种会得到 **mismatches=65**；而且它会把沈家区间的河下沿从 384 算成 416，
> 于是把合法的 `(64,416)` 误判成「压河 32px」，把车道北段的河沿从 288 算成 352（车道 y=288 会与河重叠 64px）。
其中 `x` 是**格号**（0..149 对应 0..4800px）。落地取：
```
RIVER_PTS = [[x*32, RIVER_Y[x]] for x in range(150)] + [[4800, 0], [0, 0]]
```
**落盘前自检（两道，都要跑）**：
① 拿同一个公式生成 **101 列**版本 `[[x*32, RIVER_Y[x]] for x in range(101)] + [[3200,0],[0,0]]`（103 点），与**现行** `data/frames.json` 的 a5_2026 河（103 点）逐点比对，`mismatches` 必须为 **0**；
② 再把列数改成 150 生成落盘用的 152 点版本。
**mismatches 不为 0 就是公式抄错了，先查清再落盘。**

> 实测参考值（权威公式，150 列版）：`RIVER_Y[0..9]` = **[256×9, 224]**（共 10 个值）；`RIVER_Y[10..16]` = [224×7]；`RIVER_Y[62..66]` = **[288,288,288,256,256]**；全河最大 **416** 出现在格 x=43（磨坊凹口）。
