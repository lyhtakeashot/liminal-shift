# 极简标记语法

日记渲染**不使用 Markdown**。Godot 没有内置 Markdown 渲染器，
而 Markdown 本身也没有「删除线 + 红色改正」这种语义。

改用四个自定义标记，解析器几十行，零依赖。

---

## 标记

| 写法 | 假本（通顺版） | 真本（原稿版） |
|---|---|---|
| `{{旧\|新}}` | 只剩「新」 | 旧字划掉变灰 + 新字红色加粗 |
| `{{旧A\|旧B\|新}}` | 只剩「新」 | 旧A划掉 + `…` + 新字红色加粗 |
| `---` | 淡色小圆点分隔 | 同左 |
| 行首制表符 | 缩进 | 缩进 |

就这么四个。

---

## 为什么不用 Markdown 插件

| 方案 | 问题 |
|---|---|
| MarkdownLabel 插件 | 接管 `text` 属性；13 天里多一个依赖；涂改语法仍要混 BBCode |
| 直接写 BBCode | 原稿变成 `[s]三石二斗[/s][color=#8b2f2f]三石[/color]`，写的人眼前是乱的 |
| **自定义标记** | ✅ 原文本身可读；一份原稿自动出两本书 |

**关键优势**：自定义标记能做到「同一份文本，两种渲染规则」。
Markdown 做不到——它没有「同一句话的两种真伪」这个概念。

---

## 渲染参数

实测确定，直接抄：

| 项 | 值 | 说明 |
|---|---|---|
| 被划掉的字色 | `#8f8474` | 灰，退到背景 |
| 改正的字色 | `#8b2f2f` | 暗红，加粗 |
| 删除线粗细 | **2px** | 自绘，非字体自带 |
| 删除线位置 | `y + ascent - font_size * 0.30` | 落在文字中线偏上 |
| 正文字号 | 17 | |
| 行高 | 26 | |
| 纸张色（假本） | `#e8ddc0` | |
| 纸张色（真本） | `#e2d6b4` | 稍深，旧 |
| 墨色 | `#3a2f22` | |

### 删除线必须自绘

`RichTextLabel` 的 `[s]` 标签**线宽由字体决定，不可调**，实测太细看不清。

正确做法：用 `Control._draw()` + `draw_line()` 自己画。

```gdscript
var ly := y + font.get_ascent(fs) - fs * 0.30
draw_line(Vector2(x, ly), Vector2(x + w, ly), OLD_COL, 2.0, true)
```

顺带好处：整个日记页都走自绘后，纸张纹理、行间墨渍、边缘毛边都能加。

## 中文渲染

**Godot 默认字体自带中日韩字形，不需要额外装字体。**

实测：`民国十五年十一月十七，晴。` 渲染完全正常。

## BBCode 可用性参考（实测 Godot 4.7.2）

如果自绘方案不够用，退回 `RichTextLabel` 时这些能用：

| 标签 | 支持 | 备注 |
|---|---|---|
| `[s]` | ✅ | **但太细** |
| `[color=#xxxxxx]` | ✅ | 可嵌套 |
| `[i]` | ✅ | |
| `[bgcolor]` | ✅ | 可做涂黑块 |
| `[u]` | ✅ | |
| `[shake]` `[wave]` `[fade]` `[rainbow]` `[pulse]` | ✅ | |
| `[center]` `[indent]` `[dropcap]` | ✅ | |
| `[opentype]` | ❌ | 不支持 |
| `[lb]` `[rb]` 转义 | ❌ | 不支持 |

**注意**：`[color]` 必须严格配对，不能跨段落闭合。

## 陷阱

**① `[s]` 标签的线太细**

这是本项目改成自绘的直接原因。**不要用 `[s]` 做主要视觉元素。**

**② 多段涂改直接连排会读成乱码**

`{{三十|三|二十|三十}}` 如果每个都渲染成划线+红字，会变成
`三三十二十三十` 一串，读不通。

**解决**：超过两段时折叠成「首 → … → 尾」。

```
付洋 三 十 …三十，抚。
```

玩家能看出「改了很多次」，但不会读成乱码。

**③ 假本里 `---` 也要处理**

如果只处理真本的 `---`，假本页面会露出裸的 `---`。

**两套渲染都必须处理所有标记**，只是表现不同。

## 原稿示例

```
民国十五年十一月十七，晴。

卯时开闸，放水三刻，溉田十二亩。
收粮 {{三石二斗|三石}}。
午，陆氏子过河{{。|在闸下。}}
夜，陆家来人，言子未归。
付洋 {{三十|三|二十|三十}}，抚。
---

二月。

	卯时开闸。
	未告陆家。

未告陆家。
---

春，陆家{{迁|走了|不再来了}}。
```
