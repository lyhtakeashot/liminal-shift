# AI 语音站点该怎么用 · 旁听配音取料说明（2026-11-26）

> 这份文件的用途：**你拿着去 AI 语音站点取料**，取回来的东西丢进一个目录，剩下全是我这边的事。
> `tools/gen_voice_tts.py`（edge-tts 版）**保留但降级为备胎** —— 它音色机械，只在取料失败时兜底。
> 台词权威版本仍是 `docs/npc.md` §5.5，本文件只是它的「取料说明书」，不新增一个字。

## 一、给站点用的提示词（直接复制粘贴）

### 1. 角色设定块（每换一个音色，粘一次，只改「角色」那一行）

```
你是一位没受过训练的说话人，不是播音员。

角色：{角色描述}
要求：
- 说普通话，但带明显的乡镇口音：句尾下沉、语速偏慢、「的/了」含糊带过
- 语气像在跟邻居随口聊天，不是朗诵、不是播报、不是客服
- 不要情绪饱满，不要起伏夸张；平淡、略疲惫
- 每句话之间留 0.3 秒静音
- 只输出人声，不要背景音乐、不要音效、不要空间混响
- 台词一个字都不许改、不许增删、不许润色
```

### 2. 逐句取料块（一句话一条，配上一句角色描述）

```
用上一段的角色设定，念这一句（只念正文，不念「甲：」）：
{台词正文}
```

> 如果站点一次只能出一句，就按下面表格一句一跑；能一次出多句（同一音色连续生成）就整段跑，
> 但**必须按表格顺序**，方便我按序号对文件。

### 3. 角色音色表（7 个场景只需要 4 个音色）

| 代号 | 音色要求 | 用在 |
|---|---|---|
| **W1** | 女，25–35 岁，温和，农家口音 | A1 甲 |
| **W2** | 女，40 岁上下，嗓门稍亮，爱说闲话 | A1 乙、A3 乙、A5 甲 |
| **M1** | 男，30–40 岁，干活的，声音靠前 | A2 甲、A4 甲、A2 激情案甲 |
| **M2** | 男，50 岁上下，低、慢、有点闷 | A3 甲、A4 乙、两条激情案的乙 |

**关键**：同一个代号在**所有场景里必须是同一个音色**。
A1→A2→A3 是同一批人过了 25 年、再过 25 年，**变老这一步不用你在站点做**——
我会在本地把音高和语速往下压（保留同一副嗓子，才不会听着像换了演员）。
所以你在站点只做两件事：**音色选好，一句一句念对**。

## 三、交付规格（丢进哪个目录、叫什么名字）

```
shift/assets/audio_raw/tts/<上表第一列的「文件」>.mp3
```

- 例：`assets/audio_raw/tts/a2_well_1.mp3`
- 格式：mp3 / wav / m4a 都行（我有 ffmpeg 8.1.2，什么都能吃）
- 采样率：44.1k 或 48k 都行，最后我会转成 22050 单声道
- 只要一句一个人声：**不要 BGM、不要音效、不要混响**（空间感我自己加，加了就盖不掉）
- 首尾多出来的静音不用管，我会按能量裁剪
- 目录里已有 `.gdignore`，Godot 不会去导入它

## 四、如果站点有限制，按这个优先级砍

1. **先把 4 个音色都试出来**（W1/W2/M1/M2 各念一句 `a1_bang_0` 的台词当试音，挑最不「AI 味」的）。
2. 再跑 **A1 + A2 + A3 十二句**（这三个场景是主叙事线，同一批人变老的效果全在这）。
3. 再跑 **两条激情案八句**（细节裁决，玩家会比对数字）。
4. 最后 **A4 工地 + A5 路口八句**（氛围补白，缺了只是少听两句）。

只跑完第 2 步也能上线：缺的场景我会让台词照常出字幕，但没有语音。

## 五、我接手做什么（你不用管）

1. `python tools/process_voice.py` → 解码 + 180Hz 高通 / 4kHz 低通 / 三抽头短混响 / −50dB 空气底噪 → `assets/audio/voice/*.wav`
2. **本地变老**：A2 用 ffmpeg `asetrate`+`atempo` 压 8–12% 音高（保时长），A3 压 18–25% ——
   同一副嗓子变老，而不是换个演员。
3. 逐条量峰值/时长，写 `_mdtest/voice_check.gd` 守门（28 条齐、时长 0.4–8s、不削波）。
4. 接线进 `scripts/hearsay.gd`（L20 那条线）。

## 六、取料的诚实交代

- **我听不到任何音频**，我只能保证「文件在、不削波、时长合理、可复现」。
  好不好听、像不像人，**只有你听过说了算** —— 试音那一步请在站点上自己听一遍再定音色。
- edge-tts 那版已经在 `tools/gen_voice_tts.py` 里留着，任何时候 `python tools/gen_voice_tts.py`
  都能在 2 分钟内重新出一套兜底，不会因为取料失败让整条线停住。
