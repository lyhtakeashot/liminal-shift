## 2. 【待拍板，默认按此施工】年代语义

A5/A4 的环岛是 2001 年才修的（`story.md` §7.3「2001 年十字路口修起环岛」），
所以 A1–A3 不能照抄 2026 的路面形态。默认方案（**如果总策划没另行通知，就按这个做**）：

| | 环形/车道**几何位置** | 路面**形态与材质** |
|---|---|---|
| 三帧一致 | **完全一致**（圆心 R176/R304、车道 x1984..2112、引道 y1600..1728 都不许偏差） | 逐年代不同 |
| a1 1926 | 同上 | 土路 + 车辙；环岛位置是**空地/树影**，不是柏油 |
| a2 1951 | 同上 | 碎石 + 夯土 |
| a3 1976 | 同上 | 水泥（A3 起路取直，按 `BUILD-A1.md` §2.2 v5） |
| a4 2001 / a5 2026 | （已完成，不许改） | 柏油 + 环岛 |

**为什么几何必须一致而不是「各年代各铺各的」**：玩家按 Shift 时脚下不能有一格变化。
材质可以变，通行性不能变。

## 3. 施工清单（逐帧，照 A4 重排线那五处的范式做）

对 `a1_1926` / `a2_1951` / `a3_1976` **每一帧**都要做：

1. **房子挪位**：磨坊/沈家/周家/陆家按 §1 表格落到新坐标；四家之间不许互相压、不许压河、不许压车道。
   - `shen_a*` 一律 `(64,416)`（与 A5 同址）。
   - 挪位后必须重算门/院门朝向：门不能开进环道或车道。
2. **主路改环岛**：删掉 `[0,1664,3200,64]` 这条直筒，换成「西引道 + 东引道 + 环道 + 内岛」，与 A5 **逐点同形**。
3. **补南北车道**：`x=1984..2112` 从北界贯到南界。
4. **河铺满**：按 §1 公式重生成，103 点 → 152 点，`x` 到 4800。**D1 一并修掉**。
5. **填满东南**：现在 `y` 只到 1824。新世界到 3600 ⇒ 南侧必须铺田/林/村界，
   **不许留「一走就到空地」的洞**。填法只用现有 shape 类型（rect/polygon/circle），
   按 `docs/地图视觉口径.md` **C2 只圈方格区域、不写造型**、**C6 山与装饰房暂不参与空气墙（`solid:false`）**。
6. **热点跟着走**：原地标热点（坝/田/老井/老槐/超市工地）坐标随实体一起挪，`text` 一个字不许改。

**施工顺序建议**：先在 `lab/_a13_plan.py` 里算几何并自检 → 自检 `ERRORS=0` → 再落盘。
**方案脚本与 JSON 一起交**（A4/A5 都是这么干的，可复算）。
