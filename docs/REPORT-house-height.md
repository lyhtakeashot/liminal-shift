## 五、接手者注意事项（仍需用的坑）

- **`greybox_check.gd` 的 exit code=1 是正常的**（脚本自身 quit 方式），判定看布尔行；沙箱里 `Failed to read the root certificate store.` 是固有噪声，看 `WORLD_OK` / `WALL_BLOCKED` / `REACH_OK` / `UNEXPLAINED_BLOCKS=0` / `HOTSPOTS_OK` 等关键行。
- **GDScript 类型坑**：`Dictionary.get("pos")` 返回 Variant，赋给 `Array` 型变量会报 `Trying to assign value of type 'Vector2' to a variable of type 'Array'`。要么显式声明 `var p: Array = d.get("pos", [0,0])`，要么直接 `Vector2(d["pos"][0], d["pos"][1])`。
- **数据结构语义**：`lot` 是闭区间 `[x0,y0,x1,y1]`；`wings` 是 `[x,y,w,h]`；家具 `rect` 是 `[x,y,w,h]`（宽高，不是角点）。
- **`_shot_p3d.gd` 必须带窗口跑**，不能 `--headless`（要取 viewport texture）；且视角坐标尚未按 32px 更新（见 P0 ②）。
