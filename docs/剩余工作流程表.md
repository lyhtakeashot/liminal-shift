## §5 模型调用表（百炼 tokenplan）

> **注意**：具体模型名以你**控制台「模型广场」实际可用的列表**为准，下表是候选。跑之前先在页面选一次、确认能出结果，再批量。

### 5.1 图片生成 —— 用于 N1（NPC 立绘）

| 项 | 内容 |
|---|---|
| 候选模型 | `wan2.2-t2i-flash`（快、便宜）／`qwen-image`（质量好、慢） |
| 调用方式 | 控制台「图像生成」直接出图，或 API（图像生成异步接口） |
| **关键参数** | 输出尺寸选 **512×1024 或 768×1024**（竖构图，人物全身）；风格词写死 `pixel art, 16-bit, limited palette, side-facing, full body, no background` |
| **后处理**（lead 做，不交给模型） | 降采样到 **32×64**（2 格高）→ 抠背景（纯色背景按阈值抠 / 白底直接拉 alpha）→ 二值化 + 限色到 16 色 → 输出 `assets/npc/*.png` + `.import` |
| 为什么要后处理 | AI 出不了 32×64 的干净像素图；直接缩会糊成一团。**出大图再降采样**是唯一稳的路 |
| 一致性要求 | 6 个 NPC 用**同一段风格前缀**，只改「人物描述」，否则六个人像六个画师 |
| 参考图 | 可喂 `美术资产/主角/Sprite-主角-Sheet.png` 做风格参考（图生图模式），一致性更好 |

### 5.2 语音生成 —— 用于可选重做配音（**不是必需**）

| 项 | 内容 |
|---|---|
| 候选模型 | `qwen3-tts-flash`／`cosyvoice-v3-flash`（百炼 TTS 系列） |
| 现状 | 28 条配音**已有成品**（`assets/audio/voice/`），问题是峰值 0.178–1.000 不齐（差 15dB） |
| 判断 | **重做不如修**。优先用 ffmpeg 批量拉齐响度（`loudnorm` 或简单归一），成本 10 分钟；只有听起来实在不行才重做 |
| 若要重做 | 按 `docs/配音台词卡-豆包.md` 的 6 人物卡（W1/W2/M1/M2/W3/M3），每人物一个音色，**同一人物所有句子必须同一音色** |
| 变老处理 | **不在模型做**。1926→1951→1976 同一批农妇用本地 `asetrate`+`atempo` 降速降调（`tools/process_voice.py` 已实现 `ERA_SLOW`），换音色会像换演员 |

### 5.3 音乐 —— 用于 X1（选做）

| 项 | 内容 |
|---|---|
| 可用性 | **未确认**百炼是否有音乐生成模型。若控制台里没有，X1 直接砍 |
| 兜底方案 | 程序合成（`tools/gen_audio.py` 已能出噪声类）或复用现有 13 条环境底噪 |
| 铁律 | **宁可没有 BGM，不要难听的 BGM**。评审不因「没音乐」扣分，会因「刺耳循环」扣分 |

### 5.4 不许用模型的地方

- **地图几何**（格坐标、可行走面）—— 必须程序算，AI 生成不了精确格数据
- **瓦片贴图**（32×32 地面）—— AI 出的会破坏平铺无缝，现有人工瓦片更稳
- **任何代码** —— 全部手写，AI 生成的 GDScript 在这个项目里没有验证路径
