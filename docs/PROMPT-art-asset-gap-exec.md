## §1 背景（一句话版）

《阈限迁移 SHIFT》是 Godot 4 的像素叙事游戏：主角是没人能看见的归档员，按 SHIFT 在同一座村庄的 1926 / 1951 / 1976 / 2001 / 2026 五个时代之间切换，收集证物、追一桩跨四代人的旧案。

**当前的美术状态**：A1–A3（1926/1951/1976）三层资产基本齐了（屋体 22 张、场景 20 张、家具 91 种），但 **A4/A5（2001/2026）六栋房子零张图**，场景图只有 A1–A3 有，A4/A5 全走引擎色块降级；**而且引擎里有一批现成的贴图根本没接线**（草地瓦片最典型）。用户要的是：**把「还缺哪些美术资产」理成一份能直接发给美术同学的清单**，附带尺寸规格与画法硬要求，让美术同学照着画。

### §2.1 引擎怎么画背景（决定「缺什么」的关键）

`scripts/world_view.gd` 的 `_draw_back()` 按 shape 类型分发：

| 元素 | 现在的画法 | 贴图消费点 | 结论 |
|---|---|---|---|
| **草地/地面** | `:164` `draw_rect(全屏, _grade(frame.ground))` —— **纯色**，颜色取自 `data/frames.json` 每帧 `ground` 字段（a1 `#6e7a4c` / a2 `#68744a` / a3 `#6a6a44` / a4 `#6f6a52` / a5 `#7a7a76`） | **无**。`assets/village/scene/ground_a1_tiles.png` / `ground_a2_tiles.png` / `ground_a3_tiles.png`（各 32×32 平铺瓦、100% 不透明、主色 a1 = RGB(110,122,76)）**在磁盘上，但全仓零消费点**（只在 manifest 索引与生成器里出现） | 🔴 **不是缺资产，是「有图没接线」**。清单里要写清「这 3 张要接线，不需要美术重画」 |
| **主路** | `:218-228` road rect 分支 → `AssetDraw.scene_tex(frame.id,"road")`；贴图为 null 就画纯色 rect | `scripts/asset_draw.gd:18-40` `SCENE_FILES` **只含 a1/a2/a3** ⇒ **A4/A5 没有路图，走色块** | 🔴 **A4/A5 缺路图** |

| **坝** | `:229-237` label「坝」→ 一张 `dam.png`（256×128，三帧共用） | `SHARED_SCENE` | ✅ 有 |

### §2.5 用户 2026-11-24 的三条新裁定（直接影响清单内容）

1. **A4/A5 要做环岛**（十字路口中间的环形岛），**环岛中心是老槐树**；A4 的树比环岛小，A5 的树和环岛一样大。
2. **老槐树整体缩小**：「重点是故事和游戏的完整性，树的尺寸就艺术性处理，尺寸不用完全贴合实际了」⇒ 旧刻度「直径 2→4→6→6→10 格」作废，**新刻度由本线给建议**（推荐 A1 2 格 → A2 3 格 → A3 4 格 → A4 5 格 → A5 6 格，即 64/96/128/160/192 px 冠幅；环岛内圈必须 ≥ A5 冠幅）。
3. **A1–A3 三帧看起来太稀疏**，要**加山做空间约束**、**加田地、路标之类**把空旷填掉 ⇒ 清单里要新增「山/丘陵」「路标」「田地细分」这几类**新元素**。

⚠️ 这些新元素在 `data/frames.json` 里**还没有对应的 shape 表达方式**（现有 type 只有 `rect`/`circle`/`polygon`/`house`/`path` 五种）。清单里**只描述「要画什么、什么尺寸、什么锚点」**，怎么进地图由总策划另开数据线决定。
