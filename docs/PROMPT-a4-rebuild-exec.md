### §2.5 引擎红线（`scripts/world_view.gd` / `scripts/frame_data.gd` 逐条实测）

1. **竖路 / 环道 / 内岛 / 车道 一律不写 `road:true`**。`road:true` 的 rect 会被 `_scene_bboxes()` 全部 `Rect2.merge` 成**一个外包矩形**，整张路图按这个矩形贴 ⇒ 竖路写 `road:true` 会把空地刷成柏油。竖路/环道用 polygon。
2. **每帧只能有一个 `label` 为空的 rect**（那是田图 bbox 的锚）。A4 的无 label rect ＝ 田 `[3600,320,880,384]`。
3. `label` 非空的 rect 在**背景层被 pass**，走前景层（`label` 决定贴哪个图）。
4. `label` 非空的 rect 若尺寸与贴图画布不一致 ⇒ 会被拉伸压扁（**这属 L8 资产接线的活，本线只管数据，不管贴图**）。
5. `solid:false` 的形状**完全不进碰撞**（`scripts/frame_data.gd:38`）⇒ 路/田/井/树/内岛/环道都不挡路；只有 house lot 与 `solid:true` 的世界物件（坝/山/界碑/路标）挡路。**任何几何自检都要按这个口径写。**
6. circle 的半径字段名是 **`radius`**，不是 `r`。
7. `house` shape 的 `pos` 是**世界像素原点**；`houses_data.json` 的 `lot` 是**格坐标**。世界矩形 ＝ `pos + lot×TILE`（`lot` 两端都含）。
8. `wings` 是 `[x,y,w,h]`，不是 `x1,y1,x2,y2`；`wings` 不越界 ≠ 合法，`lot` 底色重叠也算 FAIL。
9. house shape 的 `pos` ＋ house 数据缺失 ⇒ **整栋静默消失**（`HouseShape.house()` 返回空 dict ⇒ `continue`）。A4 四栋都在 `houses_data.json` 里，不会有这个问题。
10. 跨帧房子重叠是**正常的**（A3 粮站原址＝A4/A5 超市原址）；只能约束**同帧**不重叠。
