# SHIFT · 案件卷宗

> 游戏《shift》的故事设定与文本素材。
> 本文档是**唯一权威来源**，所有游戏内文本从这里取。

---

## 0. 一句话

一个被世界遗忘的侦探，用时间轴在同一个村庄里走了五次，
把一件被四代人层层埋掉的案子，归档。

---

## 1. 规则

### 1.1 主角

来自**世界刑侦陈列馆**的归档员。

- 没有人能看见他。
- 他不属于任何时间，也不属于任何地方。
- 他的职责是**如实记录真相**，不是申冤，不是惩恶。
- 他不能改变任何事，只能看，只能记。

**这决定了结局**：案子破了，但不会有人被捕。卷宗被填上，世界继续。

### 1.2 表现

一个**固定区域**，从头到尾没变过。

- 空间不动：主角只能在这个区块里走。
- 时间可动：按 Shift 在五个时间点之间切换。
- **主角唯一能移动的维度是时间。**

### 1.3 视角

2D 俯视 3/4（星露谷式），像素风。

## 2. 五帧

| 帧 | 年份 | 村子 | 这一代做了什么 |
|---|---|---|---|
| **A1** | 1926 | 三栋房屋、弯曲小路、两片农田、磨坊、井 | 沈万山放水未告，陆文溺亡 |
| **A2** | 1951 | 陆家房空，老井封了，新井在路另一头 | 沈守业把陆敬之推进井里 |
| **A3** | 1976 | 路还弯着，草长起来，农田半荒，磨坊改粮站 | 沈德昌把方师傅和井一起封进地基 |
| **A4** | 2001 | 路开始取直，粮站拆，超市在建，农田全荒 | 沈建国改地质报告，桩基绕开 |
| **A5** | 2026 | 笔直十字路口、超市、玩具店、小学、停车场 | 沈明远什么都不知道 |

**每一代都是 36 岁。**

## 3. 三家人

| | 姓氏 | 1926 身份 | 2026 结局 |
|---|---|---|---|
| 加害 | **沈** | 磨坊主，在上游筑坝 | 全县最大超市老板，捐建小学 |
| 受害 | **陆** | 田在下游，断水 | **不存在。没有后人。** |
| 帮凶 | **周** | 沈家长工，看见了，没说 | 曾孙在超市旁租铺面开玩具店 |

**结局关系**：周家的玩具店租的是沈家的楼，雇的是沈家的人。
周家三代人都不知道自己在替谁看店。
沈家第五代也不知道自己站在什么上面。
**只有陆家不在了。**

## 4. 逐代恶行

### 4.1 A1 · 1926 · 不救

沈万山在上游筑坝做磨坊。陆家的田在下游，断了水。

陆家儿子 **陆文，19 岁**，要去县里递状子。

> **沈万山没有杀他。**
> **沈万山只是在放水的时候，没有先喊一声。**

陆文过河被冲走。尸体没找到。

陆家老太爷拿了抚恤银，签了卖地契，带着儿媳搬走。

**村志两行字**：陆文「外出未归」，陆家「迁出」。

### 4.2 A2 · 1951 · 填井

土改。沈守业怕地契来源被翻。

陆家留下的遗腹子 **陆敬之**，此时是县里的工作队员，回村查地。

他查出来了：卖地契的字迹和见证人不对。

> **沈守业把他灌醉，推进了井里，然后填了井。**

村里在路的另一头重新打了一口井。老井用石板盖上，铺平。

**村志**：陆敬之「下村工作，途中失踪」。

### 4.3 A3 · 1976 · 连坐

磨坊改建粮站。挖地基，**挖到了老井**——原来磨坊一直盖在井上面。

沈德昌当场决定：不报，直接封。

施工队里有个外乡石匠，姓方，看见了。

> **沈德昌把他也留在了下面。**
> **然后倒了三层水泥。**

### 4.4 A4 · 2001 · 合法化

粮站拆了，建超市。这一次要大规模开挖。

沈建国没有杀人。他用了更干净的办法：

> **找关系改了一份地质勘察报告，写上「地下有暗河，不宜大开挖」。**

于是改桩基，桩位**绕着那片地打**。

**一具尸体都没碰，一次都没往下挖。**

### 4.5 A5 · 2026 · 洗白

沈明远当选「杰出企业家」，捐建小学。

> **他什么都不知道。**

## 5. 双日记

### 5.1 设定

沈万山一生写**两本**日记。

> **一本给官家看，一本给自己看。**
> **要真的骗过自己，才能骗过警察。**

| | 假《水簿》 | 真《水簿》 |
|---|---|---|
| 位置 | 磨坊柜台，随手翻 | 墙基暗龛，油布包 |
| 纸质 | 好纸，硬壳装订 | 糙纸，线装，边角卷 |
| 笔迹 | **极整齐，像誊抄过** | 有涂改，有划掉 |
| 内容 | 全是真话，只是删了钱 | 全是数字，偶尔一句 |
| 为什么长这样 | **因为要给别人看** | **因为只有自己看** |

**「假本写得比真本整齐」**——玩家还没读内容，先感到不对劲。
**一本天天翻的账，不可能这么干净。**

### 5.2 动机

真本没有忏悔，没有认罪。

**它是一本他做不平的账。**

沈万山是磨坊主，记账是对账的职业习惯。
他生命里唯一对不平的一笔，只能另外记一本。

**字迹开始乱的地方，才是他真正的时刻。**

### 5.3 揭晓节奏

**双日记只能用一次。** 分成三段，每段必须卡住：

| 帧 | 拿到什么 | 能得出 | 为什么不够 |
|---|---|---|---|
| **A2** | 假本续记 | 沈守业为保地害死陆敬之 | 仍是「灭口」，动机猜错 |
| **A3** | **真本被发现** | 1926 是沈万山亲手做的 | **只有自述，没有旁证，档案填不了** |
| **A4** | 土地登记表第二联 | 沈家一直在给陆家钱 | 可能是补助，可能是借 |
| **A5** | 周有田往来账 | **陆敬之二十四年来一直在勒索** | 完整反转成立 |

**证词（A3）→ 模式（A4）→ 铁证（A5）。**

### 5.4 最冷的一刀

真本出土的那一刻，害死了第三个人。

沈德昌看到祖父的手记，**决定把知情人一起封进地基**。

> **真相本身就是凶器。**

### 5.5 最后一笔

真本停在 1951 年。

> **一个记账的人不记了。**

后面二十年空白。他没销毁它，只是不再写了。

## 6. 虚构反转

玩家原以为 1951 年是「沈守业怕地被翻，杀人灭口」。

**真相是：陆敬之二十四年来一直在勒索。**

| 文件 | 帧 | 说什么 |
|---|---|---|
| 真本《水簿》 | A3 | 「敬之来，取银第三回」——但这是杀人者的自述 |
| 土地登记表第二联 | A4 | 亩数被人改过，改的人是陆敬之自己 |
| 周有田往来账 | A5 | 纯数字，一季一次，二十四年，三十七笔 |

周有田是沈家的长工兼账房。**他记了二十四年的账，一辈子没说过一个字。**

**于是档案里的结论被改写：**

```
原本要填：案件性质 = 杀人灭口
必须改填：案件性质 = 债务纠纷
```

**陆敬之，男，三十七岁，死于债务纠纷。**

**没有人被平反。因为没有人是无辜的。**

## 7. 贯穿百年的物证

### 7.1 路的弯

路本来该是直的。**它绕了一个弯，因为 1926 年那里有一口井。**

井 1951 年填了，磨坊 1976 年盖上了，超市 2001 年压上去了。

**2026 年，路取直了。**

| 帧 | 路 | 玩家能看出什么 |
|---|---|---|
| A1–A3 | 弯，绕开井和磨坊 | 绕得很自然，不像故意的 |
| A4 | 开始取直 | 取直那段**正好经过老井** |
| A5 | 笔直十字路口，车流顺畅 | **井现在在车道正下方** |

**「路不会自己变直。」** 取直意味着有人出钱、有人批、有人施工，
而那条弯为什么非得绕那一下——成了一个必须被解决掉的问题。

### 7.2 现代场景的物证清单

1. **十字路口中央一块圆形沥青补丁**——反复修补，颜色和周围不同。
   **因为井筒下面是空的，路面会缓慢沉降。**
   那块补丁每修一次，就是在替一百年前那口井补一次疤。
2. **红绿灯基座不在正中**，偏了两米——因为地下是空的，桩打不下去。
3. **四个转角三个盖了楼，只有一个是空的**——上面画了三个停车位。
4. **地下排水管有一段是弯的**——地面取直了，地下还保留老路走向。
   **地下比地面诚实。**
5. 一块旧界碑，嵌在小学围墙里，字磨掉一半，只能认出一个「周」。
6. 超市门厅摆着老磨坊的上磨盘，刻着「沈氏丰源 · 一九五七」。
7. 玩具店招牌下面一行小字：「本店由沈氏物业出租」。

**第 1 和第 4 条是钥匙。** 一个是「路一直塌」，一个是「地下还弯着」。
把这两个并排一看就会明白：**地下有个洞，而且那个洞一直在。**

### 7.3 老槐树

1926 年种在井边，是树苗。2026 年，它把超市门口的地砖拱裂了。

**从 1951 年开始，树朝远离井的方向倾斜。**

因为井填了以后地下空了，树根往一边长。
**这个倾斜在五帧里一直存在，而且 A2 那一帧突然变大。**

## 8. 三段式揭晓

**每一段都落在不同帧，逼玩家来回刷时间。**

| 阶段 | 帧 | 玩家拿到 | 卡在哪 |
|---|---|---|---|
| **证词** | A3 | 真本自述 | 只有一面之词 |
| **模式** | A4 | 登记表 + 备忘却 | 只有钱的痕迹，没有性质的证据 |
| **铁证** | A5 | 周有田往来账 | 完成反转 |

**归档表要显示「未确认」：**

```
A3：
  1926 事件性质：★ 已确认
  1951 事件性质：未确认（付款性质不明）
  涉案人数：  未确认
```

```
A5：
  1926 事件性质：★ 已确认
  1951 事件性质：★ 已确认（债务纠纷）
  涉案人数：  三
  未寻获：    一名（陆文，民国十五年，下游）
```

**「未确认」这三个字本身就是玩法。** 它指方向，不给答案。
**没查到的东西，不许猜。**

---

## 9. 留白

- **陆文（1926）的尸体从未被找到。** 死在水里，冲到下游，一百年没人捞。
- **周家曾经是这块地的主人。** 只有一块界碑，「周」字被磨掉一半。
  玩家可能推出来，也可能永远不确定。
- **陆敬之的笔记**停在「今夜去老井看看」，之后空白。

## 10. 结局

玩家在 A5，站在超市里。

他按下「标记位置」，标在十字路口那块圆形补丁下面。

```
档案编号：7231001
地点：██村 东街
事件：连续非自然死亡
埋尸位置：＿＿＿＿
埋葬人数：＿＿＿＿
最早一具：＿＿＿＿
```

**然后——什么也没有发生。**

超市继续营业。收银机在响。沈明远正在小学剪彩。

陆家的卷宗被填上了。存在陈列馆里。

**没有人被捕。没有人被平反。没有人知道。**

**而陈列馆比所有人都活得长。**

> 本案已归档。
> 世界刑侦陈列馆 · 第七十二万三千零一卷

**不要写「正义得到伸张」。一句都不要。**

## 附一.2 · 沈万山《水簿》· 真本原稿（渲染源）

> 同一份文本，带标记。渲染器据此产出「真本」画面。

```
民国十五年十一月十七，晴。

卯时开闸，放水三刻，溉田十二亩。
收粮 {{三石二斗|三石}}。
午，陆氏子过河{{。|在闸下。}}
夜，陆家来人，言子未归。
付洋 {{三十|三|二十|三十}}，抚。
---

二月。

	卯时开闸。
	未告陆家。

未告陆家。
未告陆家。
---

春，陆家{{迁|走了|不再来了}}。
```

### 这一页里发生了什么

| 原文 | 真本显示 | 含义 |
|---|---|---|
| `{{三石二斗\|三石}}` | ~~三石二斗~~ **三石** | 收成被改少了 |
| `{{。\|在闸下。}}` | ~~。~~ **在闸下。** | 事后补的细节，补成了对他有利的 |
| `{{三十\|三\|二十\|三十}}` | ~~三十…~~ **三十** | 改了四次，每次都少一点 |
| `未告陆家。` ×2 | 原样 | 同一天的事写了两遍，一遍比一遍短 |
| `{{迁\|走了\|不再来了}}` | ~~迁~~…**不再来了** | 官方记录是「迁」，他写的不是 |

**注意最后三行**：同一天的事，他重复写。
**这不是修辞，是记账人的强迫症发作了。**

# 附二 · 标记语法

日记渲染使用极简标记，**不使用 Markdown 渲染器**（Godot 无内置支持）。

| 写法 | 假本（通顺版） | 真本（原稿版） |
|---|---|---|
| `{{旧\|新}}` | 只剩「新」 | 旧字划掉变灰 + 新字红色加粗 |
| `{{旧A\|旧B\|新}}` | 只剩「新」 | 旧A划掉 + `…` + 新字红色加粗 |
| `---` | 淡色小圆点分隔 | 同左 |
| 行首制表符 | 缩进 | 缩进 |

**一份原稿，两种渲染。** 写一遍，游戏自动生成两本书。

### 渲染参数（实测确定）

| 项 | 值 |
|---|---|
| 被划掉的字色 | `#8f8474`（灰，退到背景） |
| 改正的字色 | `#8b2f2f`（暗红，加粗描边） |
| 删除线粗细 | **2px**（自绘，非字体自带） |
| 删除线位置 | `y + ascent - font_size * 0.30` |
| 正文字号 | 17 |
| 行高 | 26 |

**删除线必须自绘。** `RichTextLabel` 的 `[s]` 标签线宽固定不可调，太细看不清。

# 附三 · 写作纪律

三条，违反就破坏整个设计：

**① 只写看到什么，不写意味着什么**

- ✅「地上有一圈比周围颜色深的方形痕迹」
- ❌「这里曾经有一座建筑」

**② 日记只记行为和数字，不记判断和动机**

- ✅「放水三刻。未告陆家。」
- ❌「我很内疚，但我不敢说」

**③ 真相不能靠「又发现一份文件」**

「真假两份记录」全片只用一次。
其余所有证据必须是**物理的、不可伪造的**：

| ✅ 可以用 | ❌ 不能用第二次 |
|---|---|
| 圆形沥青补丁 | 第二本假笔记 |
| 红绿灯基座偏移 | 第二封伪造的信 |
| 地下还弯着的排水管 | 第二份涂改过的契 |
| 老槐树倾斜的方向 | 第二个「私生子」 |
| 字磨掉一半的界碑 | 第二次「身份反转」 |

**文件说的话等于人的话，物理证据说的话等于物件的话。**
主角只信后者。

# 附四 · 与 SHIFT 主题的关系

> **主角唯一能移动的维度是时间，而一百年里唯一没有移动过的东西，是那块地砖。**

空间冻结、时间可动、位置不变——**这既是玩法，也是这个故事的主题。**
