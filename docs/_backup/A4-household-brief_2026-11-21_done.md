# A4 陆家地块这户人家 · 人物与对话补全（交接提示词）

> 交给接手的 agent：读完这一份就能开工。目标是把现在「无人物」的 A4 外来户小楼，补成一户能通过交谈给出**片面、错位、错误**往事的人家。

---

## 0. 你的任务

给 A4（2001）陆家老宅地块上那户「外来户」补全两样东西：

1. **人物设定**：这户人家是谁、从哪来、叫什么、各自知道什么。
2. **与主角交谈的对话文本**：主角通过对话获得关于这块地/村子的往事信息——必须是**片面或错误的**，作为「人嘴给方向，物证给结论」的旁证层，**绝不给出结论**。

同时提出一个**替代 `lu_a4` 的新命名**（id + 显示名），因为用户明确这栋房子不能再叫 `lu_a4`——它不再只是"一块地上的房子"，而是"一户可以交谈的人家"。

---

## 1. 硬边界（先读，别推翻）

- **故事唯一权威**：`docs/story.md`。人物身份、事件、纪年一律以它为准，不得另造与之冲突的事实。
- **人声唯一权威**：`docs/npc.md`，重点读 §0 三条铁律 / §1 主角怎么说话 / §3 对话 5 位关键人 / §4 结构模板 / §5 待写清单与旁听素材表。
- **三条铁律**（npc.md §0）：
  1. 主角不能改变任何事（说话、对方回答、指路、生气——世界不动）。
  2. 对方说完就忘（转身那一刻就忘，机制闸门）。
  3. 他永远不回答"你是谁"（五个名字，五个年代常见名；A4/2001 = **陈小军**，NPC 反应「小军，外头来的吧。」）。
- **旁听和对话永远不进归档表**（story.md:960、npc.md §5）。
- 不碰 `_ref/houses/` 的结构数据、`scripts/`、`data/frames.json`；本任务只交付**文案 + 命名建议**，技术实现由主 agent 执行。

## 2. 这户人家的现状（已知事实，不要改）

- 房屋数据 id：`lu_a4`，名「陆家地块 · 外来户二层小楼 · A4 2001（不知情）」。
  - 数据脚本：`_ref/houses/_redo_lu_a4.py`（幂等，从 `lu_a2` 派生结构）。
  - 当前图：`_ref/art/A4_2001/lu_a4.png`。
  - 家具 19 件：席梦思大床、衣柜、梳妆台、电视柜、沙发、茶几、彩电柜、饭桌、柜式空调、坐便器、洗手盆、淋浴、煤气灶、橱柜、双开门冰箱、水池、院子摩托车、晾衣架、花坛。房间：主卧/客厅/卫生间/厨房。
- **设定链**：陆家老宅 1926 后地契归沈家（story.md:526）→ 1951 空屋 → 1976 塌成废墟（`lu_a3`）→ 2001 这户普通人家在旧址盖起瓷砖外墙二层小楼。**他们完全不知道脚下曾是陆家老宅，也不知道老井和埋在下面的人。**
- 主题落点：全篇「没人知道」——沈家第五代不知道自己站在什么上面，周家三代不知道在替谁看店（story.md:64-67），**这户人家不知道脚下埋着谁**。他们的热情、平常、毫无戒心，本身就是主题。
- **现状缺口**：这栋房子目前完全没有人物——没有姓名、没有成员、没有对话。你要把这块补上。

## 3. 必须守住的叙事规矩（决定成败）

1. **片面 ≠ 谎言，错误 ≠ 胡编**：他们给的信息要从"真事被时间磨歪"里长出来，正好对上 npc.md §5 旁听素材表的梯度——**赔偿 → 天灾 → 遗忘 → 迷信 → 邪门**。他们不是知道真相在撒谎，是根本不知道，只攥着几句听来的、错位的、自洽的碎话。
2. **不知情是硬设定**：他们不知道陆家、陆敬之、方师傅、老井真相、账房暗龛、地质报告。任何他们说出的"往事"，只能是村里流传的版本（多半错年代 / 错因果 / 错对象），绝不能是他们亲历或家里传下来的准信。
3. **人嘴给方向，物证给结论**（npc.md §2.3）：他们的话只让玩家"知道该去哪儿找"，**不能替代物证下结论**。玩家听完他们的话，仍然应该是零。
4. **激情案标尺**（npc.md §5）：真正的案子（地界打架、水渠打人）细节全对、有判决、有人负责；沈家那几件越传越不像。让这户人家的话落在「不像」那一侧。
5. **主题靠反差**：2001 这户人家越是把这栋新房子说得平常、体面、日子红火，玩家越能感到"没人知道"的重量。不要让他们神秘兮兮、若有所思——那会破坏设定。

---

## 4. 主角与对话的硬规则（npc.md）

- 主角底色**冷**：只陈述事实，像念档案。不评价、不共情、不解释自己。
- **单次开口 ≤ 12 字**（npc.md §1.4）。
- **2001 腔调＝打工腔**：如「这井啥时候填的？」「这地基啥时候起的？」
- 结构模板（npc.md §4.2）：
  ```
  [玩家按 E]
  主角：这口井，几时填的？
  NPC ：（愣了一下）……填了有几年了。你问这个做什么？
  主角：记一下。
  NPC ：哦。（转身）……咦，我刚跟谁说话来着？
  [对话结束]
  ```
- **固定收尾**：「（转身）……咦，我刚跟谁说话来着？」每段对话都要。
- **重复行为**（npc.md §4.3）：玩家再按一遍，NPC **一字不差**重说同一句、同一个收尾。不随机、不换。按到第三遍玩家自己发毛——世界不会累积任何东西。
- **一致性难点（必须在交付物里处理）**：npc.md §3 原本定「5 位关键人 + 其余 NPC 只旁听不对话」，其中 **A4 帧原本没有对话对象**。你现在是在新增一个 A4 的可交谈人家。请在交付物里明确：这户人家是否成为 A4 的对谈者、如何写进 §5 待写清单（新增一项或并入现有项）、以及这是否破坏"其余 NPC 只旁听"的总格局。**不要让随便哪个 NPC 都能聊**——对话对象应该是明确的、有理由的。

## 5. 可榨取的"往事"素材（这家人能给出的片面信息）

取材自 npc.md §5 旁听素材表 A4 列，**都要错年代 / 错因果 / 错对象地讲，或讲得自相矛盾**：

| 事 | A4 村里流传的版本（可给他们说） | 真相（他们绝不能说出） |
|---|---|---|
| 陆文之死 | 「这地基底下好像有东西，老人都这么说」 | 沈万山放水未告，陆文溺亡 |
| 陆敬之失踪 | 「老井填了，新井在路那头」——**只记得井，不记得人** | 沈守业把他推进井里、填井 |
| 方师傅 | 「七六年赶工期死过个人，报上没说」 | 沈德昌把他封进地基、倒三层水泥 |
| 老槐树 | 「这树不能动，动了出事」 | 井填了地下空，树根歪长 |
| 超市工地 | 「那路口老塌，邪门」 | 桩基绕开老井那片地（地质报告造假） |

**关键**：以上任何一句都不能拼出真相。他们可以互相矛盾、可以把 1976 的事挂到 2001 头上（这正是证据——没人真的跟着这件事活过）。

## 6. 交付物

请写进 `docs/npc.md`（或单独文件后告知落点）：

1. **新命名建议**：替代 `lu_a4` 的 id + 房屋显示名。要能表达"一户人家"而非"一块地"，并符合五帧命名气质。
2. **人物卡**：户主/成员姓名、年龄、身份、性格、他们自己的来历（从哪儿搬来、为什么买这块地），以及每人分别知道/不知道什么。
3. **对话文本**：至少 1 段完整对谈（主角问 → NPC 答 → 忘句收尾），可多段。每段标注「玩家该听出什么方向 / 不该得出什么结论」。
4. **与 npc.md 的对接说明**：这段对话落在 §5 清单哪一项、是否新增 §3 关键人之外的一位、如何与 §2.3「人嘴给方向」保持一致。
5. **给主角的问句候选**：2–3 句，≤12 字，2001 打工腔。

> 命名定下来后，由主 agent 负责改数据 id、帧映射、脚本与图输出；你只给建议，不要自己动那些文件。

## 7. 绝对不要

- 不要让这家人知道或说出陆家、陆敬之、方师傅、老井真相、暗龛、地质报告的实情。
- 不要让主角长篇解释、评价、共情，或回答"你是谁"。
- 不要让 NPC 记住主角——收尾必须忘。
- 不要让对话内容进归档表。
- 不要让这户人家"隐约察觉"或"欲言又止"——他们真的什么都不知道，这正是主题的落点。
