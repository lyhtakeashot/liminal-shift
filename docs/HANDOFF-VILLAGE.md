## §2. 坐标系与画法约定（先看懂这个再改数据）

**格坐标，一格 = 16×16 px。所有 `lot` 都是含墙的占地外框。**

```
lot = [x0, y0, x1, y1]        占地矩形（含墙、含院子）
wings = [[x, y, w, h], ...]   屋本体的"翼"，翼坐标含墙
partitions = [[x1,y1,x2,y2]]  内部隔墙线段（水平或垂直，端点含）
doors = [[x,y]]               房门，必须落在墙上，渲染成 D
gate = [[x,y]]                院门/大门，渲染成 G
rooms = [[x0,y0,x1,y1,"名称","配色key"(,可选,"top")]]
furniture = [{name, short, rect:[x,y,w,h], note, clue, zone, yard_building}]
```

**四条硬规则（都被写进 `check_all()` 断言，违反就报错）**：

1. **房间矩形不包括墙。** 房间块里一格墙都不能有——这是用户 11/19 明确要求。自动拆分出的房间要用 `_fix_rooms.py` 的 `split_by_partitions()` + `clip_free()` 处理（只剥离「整条边全脏」的边，否则会误杀天井）。
2. **家具不得压门、不得重叠、不得越界**，且有门的地方四面至少一边能通行（`.` 或空格且无家具）。
3. **每栋至少有 1 段内部隔墙**（用户否过一次「墙全去掉」）。
4. **院子建筑（茅房）里可以有嵌套家具（茅坑）** —— 这是刻意的，`yard_building` 标记让断言豁免。

**L 形的唯一正确摆法（我错过两次，别再错）**：

> 字母 L = 竖在左、横在底，空位在右上。
> **「向右旋转 90°」= 竖在左、横在顶，空位在右下。**
> 沈家 A2 用的就是这个：正房 23×12 横在北，西厢 10×6 从左侧向南伸，右下 13×5 是院子。

**普通矩形房子四角天然缺一格**，不用额外做凹角：`build_grid()` 的 `is_wall` 只认「四邻有室内格」的格子，墙角两邻都是空，天然不算墙。

## §4. 编辑器怎么用

1. 双击 `_ref/houses/启动编辑器.bat`（或跑 `editor_server.py`），浏览器开 `http://127.0.0.1:8765`
2. 顶部下拉：按帧分组选房子（A1_1926 / A2_1951 / …）
3. 左上工具：`select` 点选拖动 / `wall` 画隔墙 / `door` 放门 / `gate` 放院门 / `room` 画房间 / `furn` 放家具
4. 右侧：XYZW 四个滑块调范围；房间可改名字、配色 key、是否 `top`（名字画到矩形上方，防被家具盖住）；家具可改名字、勾「线索」（橙框）、勾「院子」
5. **💾保存** → 写回 `houses_data.json`（原子写，tmp + `os.replace`）
6. **🔄重新出图** → 跑 `gen_all_houses.py`，返回 stdout
7. **↩重载** → 丢弃未保存改动

**保存后坐标会一直是 int**（已验证：`ConvertTo-Json -Depth 20` 回写再读，12 栋全部无损；新增第 13 栋后同机制有效）。

**主角参照位置**：`auto_player_at()` 自动放在**占地右下角**（`(x1, y1-1)~(x1, y1)` 那两格），院子空格优先、室内次之。主角是尺寸参照，脚格不能是墙/门/家具，头顶格可以压屋墙（设定上他能穿墙）。

## §5. 踩过的坑（血泪，按踩的次数排）

1. **改完生成器必须重跑 + 把图给用户看，两步缺一不可。** 只 edit 代码不重跑 = 用户回「图没产出啊，我没看到啊」。
2. **`pwsh` 跑 Python 偶发 `OSError: [Errno 22] Invalid argument`**（写 PNG 时）。`Start-Sleep -Seconds 2` 后重试即成功。
3. **本机所有 `pwsh` 调用都要 `sandbox_permissions: "danger-full-access"`** —— 工作区目录缺「更改权限」（ACL 诊断结论 `PRECONDITION / needs WRITE_DAC`）。这只影响命令启动，不影响文件读写。
4. **房间压实墙是最常见的隐性错误**，因为房间色块会盖住墙格、肉眼看不出。`check_all()` 已加断言；新增房间后一定跑一遍。
5. **删掉一段墙之后要检查房间配色有没有留下无主格**（露默认棕色）。A2 磨坊删了 x=5 下半段墙后，`(5,4)-(5,7)` 变成可走地面却没房间归属，用户一眼看出「颜色还没改正」。
6. **配色 key 要先在 `gen_all_houses.py:46` 的 `C["room"]` 里加**，否则 KeyError。现有：`bed / hall / store / kitchen / account / yard / shop / class / mill / toilet`。
7. **家具源图高度通常比占地多一格**（星露谷画了朝向镜头的立面）。**占地看数据，不看 PNG 像素。**
8. **`editor.html` 的文本输入值用手拼 `value="..."`，没做 HTML 转义**。中文名没有单引号所以没炸，但别在名字里放引号。
9. **别把 L 形做成整块矩形**，也别做成镜像（我错过两次：一次做成矩形，一次做成「竖在右、横在顶」= 水平镜像）。
10. **`check_all()` 抓不到「家具压墙」和「进门正对家具」**（它只校验房间不压墙、门至少一侧可通行）。`mill_a3` 单据柜曾整个塞进墙格、`shen_a3` 曾家具正对门，都是用户肉眼发现的。新建/重排家具的幂等脚本末尾要自己加自检：①遍历门/院门四邻格禁止家具；②`import gen_all_houses.build_grid`，家具每格落在 `#`/`D`/`G` 即 assert 报错、数据不落盘。
11. **拆墙格底色不要一律画成深绿院子**。内隔墙拆了应恢复室内地板色，临院/天井的墙拆了才是露天。判定写在 `gen_all_houses.py` 的 `build_grid()`（拆墙格四邻两侧都室内 → `'.'`，否则 `' '`）。`mill_a3` 厅仓打通（室内）与 `shen_a3` 连廊↔天井（临院）两种情形都靠这套判定区分。

## §7. 建筑全部定稿之后：怎么接进游戏

**现在的游戏里，房子还是 `data/frames.json` 里的灰盒色块**（每栋就一个 `rect`，68×48 px，`solid: true`）。真正的房子要接进去，需要三件事：

### 7.1 房子数据要能被游戏读到

`data/frames.json` 现在只认 `rect / circle / path` 三种 shape（`scripts/frame_data.gd:24` 的 `setup()`）。两条路：

- **A（推荐）**：新增一种 shape `{"type":"house", "id":"lu_house"}`，游戏启动时读 `_ref/houses/houses_data.json`（或把它拷成 `data/houses.json`），按 `wings` 画占地、按 `partitions` 画内墙、按 `rooms` 填地板——**一份数据两处用（出图和游戏），不重复维护**
- **B**：把每栋房子烘焙成若干个 `rect` 塞进 `frames.json`。简单但改一次房要重新烘焙

### 7.2 碰撞怎么算

沿用现在的纯数据 AABB（`scripts/frame_data.gd:64` 的 `is_free()`），**不要引物理引擎**——理由见 `docs/HANDOFF.md` §3.3/§3.4（`visible=false` 不关碰撞、disabled 的 `CollisionShape2D` 做不了目标帧检测）。

房子的墙 → `solid_rects`；门洞 → 挖空（不放 solid）；家具 → 按 `zone` 决定是屋内阻挡还是可穿过。

### 7.3 三层渲染 + 深度排序

`docs/house-spec.md` §4.5 已定：`base`（地板+墙内侧，屋内外都画）/ `roof`（屋顶，屋内隐藏）/ `props`（家具，屋内画）。屋顶淡出条件是「玩家进入建筑占地矩形」，与轴无关。

原型跑在 `_mdtest/interior_canvas.gd`，`_mdtest/interior_check.gd` 验证过（`ALL PASS`，62 面墙 / 43 个室内格 / 屋顶 alpha 归零）。

### 7.4 顺带要改的

> **A1 的具体坐标表、房屋接入代码怎么改、验收标准 → `docs/BUILD-A1.md`**（那份是逐条作业单，本文只讲原则）

- **地图要放大**：`data/frames.json` 的 `world` 现在是 `640×360`，最大的四合院占 336×304 px，塞不下几栋。建议 `1600×900`。镜头系统已经支持跟随（`scripts/camera_rig.gd`，大地图自动生效，小地图自动锁死）。
- **起始帧反转**（`docs/house-spec.md` §4.7）：`scripts/timeline.gd:58` 现在是 `index = 0`（A1 开局），要改成 A5 开局。
- **九档家具 / 证物数据**（`docs/house-spec.md` §4.6）：证物格式已重设计成「身份全局唯一 + 每帧 `states`」，还没接进代码。
