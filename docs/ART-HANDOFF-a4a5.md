## 5. 怎么交（Git 流程）

1. 仓库：`https://github.com/lyhtakeashot/liminal-shift`（公开，Collaborator 权限已给，需要你**接受邀请**）
2. 拉代码：
   ```
   git clone https://github.com/lyhtakeashot/liminal-shift.git
   ```
3. **建分支**（别直接改 main）：
   ```
   git checkout -b art/a4a5-assets
   ```
4. 文件放进去（路径一字不差）：屋体 `assets/village/houses/<族>/a4_base.png` 等；场景 `assets/village/scene/<名字>.png`；家具 `assets/village/props/...`（**目录与命名我们这边会按你的清单补齐，你只要把文件名按明细表的「短名 + 占地」给，我们来放**——如果你更习惯自己放，问我们，我们给你目标路径表）。
5. 提交 + 推分支 + 开 PR：
   ```
   git add assets/village/        # 只 add 你自己那批
   git commit -m "art: A4/A5 屋体与场景资产"
   git push -u origin art/a4a5-assets
   ```
   然后在 GitHub 上开 Pull Request 到 `main`。

> ⚠️ **不要 `git add -A`**（仓库里还有别的同学/别的线的改动，全加进来会打架）。只 add 你自己新增/修改的那批文件。
