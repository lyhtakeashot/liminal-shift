## 1. 硬规范（照抄 A1–A3 那套，别改）

| 规则 | 值 |
|---|---|
| 一格 | **32 × 32 px** |
| 屋体 base/roof 画布 | **占地宽×32 × (占地高×32 + 32)** —— 顶部多出的一格是「墙立起来」的高度 |
| 家具画布 | **占地宽×32 × (占地高×32 + 32)** —— 同样顶部多一格 |
| 锚点 | **一律底部中心**（底边贴占地底边，水平居中）；河/路/田这类**整帧图**例外，按帧坐标左上角对齐 |
| 透明边 | 家具四周留 **2px** 透明，不要顶格画死 |
| base / roof | 同宽同高同锚点；玩家进屋时 roof 淡出、base 留在地上 |
| 家具尺寸 | 以清单给的占地为准（主流九档 1×1 … 3×3；黑板/讲台是 4×1，照清单别改） |

## 6. 怎么交（Git 流程）

1. 仓库：`https://github.com/lyhtakeashot/liminal-shift`（公开，Collaborator 权限已给，需要你**接受邀请**）
2. 拉代码：
   ```
   git clone https://github.com/lyhtakeashot/liminal-shift.git
   ```
3. **建分支**（别直接改 main）：
   ```
   git checkout -b art/a4a5-assets
   ```
4. 文件放进去（路径一字不差）：屋体 `assets/village/houses/<族>/a4_base.png` 等；
   场景 `assets/village/scene/<名字>.png`；家具 `assets/village/props/<拼音>_<宽>x<高>.png`。
5. 提交 + 推分支 + 开 PR：
   ```
   git add assets/village/houses assets/village/scene assets/village/props
   git commit -m "art(a4a5): 屋体14 + 场景/环岛/新增元素 + 家具"
   git push -u origin art/a4a5-assets
   ```
   然后在 GitHub 上开 Pull Request 到 `main`。

> ⚠️ **不要 `git add -A`**（仓库里还有别的线没提交的改动，会一起被带进 commit）。只 add 上面三个目录。

## 7. 交完之后（接线，由我们做）

引擎侧还有一条「资产接线」线：把新贴图接进 `scripts/asset_draw.gd` / `scripts/world_view.gd`。
交接前先知道这几件事（**不用你操心**，但接线完成前你交的图在游戏里还看不到效果）：

1. `SCENE_FILES` 只有 a1/a2/a3 ⇒ 要补 a4/a5 条目（河/路/田/井/树），`road_a5_vertical` 还要新增 key。
2. `SHARED_SCENE` 里界碑是五帧共用一张 ⇒ 要拆成按帧取。
3. `world_view.gd` 的 `FAMILY` 只到 a1–a3 ⇒ A 组 14 张要先补表，否则 `_house_tex()` 不会去找这些文件。
4. `FAMILY` 是「一 id 一图」⇒ `market` 在 A4/A5 共用同一个 id，必须改成按帧取图，否则两套屋体只有一张生效。
5. 路口几何要从 64×64 扩到 320×320，环岛图才不被拉伸。
