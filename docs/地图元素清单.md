## 2. 逐帧「该长什么样」

- **A1 1926**：土路、弯；四栋房（沈/周/陆/磨坊）；井是敞开的坑且**挡路**；槐是树苗；东边零散私田；没有车道、没有环岛、没有路标、没有山。
- **A2 1951**：同 A1 的骨架（路还是弯），沈家加盖、槐长粗；井口盖石板。
- **A3 1976**：**路取直**（这是 A3 的辨识特征）；沈家起成三层楼；槐冠压到路边；磨坊最高。
- **A4 2001**：**这一年才出现环岛**——南北车道 + 环道 + 内岛，槐被围在岛心；磨坊拆掉、超市在建（代替陆家那块地）；郑家落在南片；路面开始铺柏油。

## 4. 已拍板 / 仍待拍板

已拍板（2026-11-26）：①老槐五帧钉在 **(2048,1664)**，百年不动；②A1 零散六小块、A2 四块、A3 一整块；③音频处理问题**冻结**，见 `docs/待解决事项.md`。

**仍待拍板 1 条 —— 河要不要更弯。** 实测：河岸线（南沿）现在 y=160..416，总起伏 **256px**，但其中 200px 是磨坊那**一个**大湾贡献的，其余全程只有一个宽缓起伏 ⇒ 看上去像一条直线。五帧**共用同一条河**，所以要更弯就得五帧一起改（A4/A5 的 `.tscn` 与空气墙数字也会跟着变）。改法：在 `river_depth(x)` 上加 2–3 个振幅 96–128px 的小弯，且不许越过 y=416（沈家北墙线）。**不点头就不动。**
