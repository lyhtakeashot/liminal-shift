## §1.5 单位（先读这条，违反即返工）

**一切几何按「格」想、按「格」写。1 格 = 32px，这是本项目的最小单位。**

- `data/frames.json` 里存的是 px（历史存法），落盘时 `px = 格 × 32`，读回时 `格 = px / 32`。
- 任务书、自检输出、反馈文档里**先报格，px 只放括号里**。凡是只给 px 不给格的坐标，视为不合格。
- 世界 = **150 × 112.5 格**（4800 × 3600 px）。高度不是整数格，这是既有事实、不是笔误，别去「修」它。
- 已知有历史数据落在半格上：`a4/a5` 的田 `[3600, 320, 880, 384]` px = `[112.5, 10, 27.5, 12]` 格。**这处不许动**，只在反馈里登记。

## §2 硬约束（违反任意一条即返工）

1. **路宽恒 2 格**：每块 `rect` 记作 `[x, y, 1, 2]` 格（= `[x*32, y*32, 32, 64]` px）；`x`、`y` 必须是整数格。
2. **相邻块 |Δy| ≤ 1 格**（不许出现 2 格的台阶）。
3. **老槐红线**：槐心 `(64, 52)` 格五帧不许动（用户定案「百年不动」）。任何路面矩形都不许与这棵树的地面冠幅圆相交：
   - `a1_1926` 冠 r=1 格 → 不许进入 `y ∈ [51, 53]` 格（1632..1696 px）
   - `a2_1951` 冠 r=2 格 → 不许进入 `y ∈ [50, 54]` 格（1600..1728 px）
   - `a3_1976` 冠 r=3 格 → 不许进入 `y ∈ [49, 55]` 格（1568..1760 px）
   ⇒ **三帧主路带统一放 `y = 46..48` 格**（1472..1536 px），天然在树北侧，离 a3 冠缘还有 1 格。
4. **不许用单一周期函数**（正弦 / 余弦 / 三角波 / `sin(x/1400)` 这类）生成中心线。必须用控制点插值（Catmull-Rom 或线性），**控制点数 ≥ 4 且 ≤ 7**（上一版 11 个控制点就是「曲折太多」的来源）。每一个弯都要在反馈里写一句它为什么在那儿（绕树 / 让开院门 / 贴田埂 / 让开井台），**写不出理由的弯直接删**。
5. **A3 主路必须是一条直线**（`docs/BUILD-A1.md:86`「A3 起路取直」），单一 `y` 值贯穿 0..4800。
6. **支路不许直角**：任何一条支路的相邻两段夹角必须 < 150°（即必须有斜段），拐点处用一块 32px 倒角块过渡；支路宽度同样 64px。
7. **院门坐标只读**：端点必须落在 `_ref/houses/houses_data.json` 里该栋 `gate` 格朝外的那条边上（距格心 ≤ 24px）。**不许为了让支路好画而改 gate 或 lot。**
8. 房子的 `pos` 只允许改 §1 第 2 条点名的周家三帧，其余房子的 `pos`、`id`、`wings`、`partitions` **一字节不许动**。
9. **hotspots 数组五帧完全不变**（标题、坐标、reach 一个都不许动）。
10. 改动必须可复现：写一个 `lab/_a13_road_v4.py`，支持 `--check`（只自检不落盘）和 `--write`，幂等。
