# 旁听配音 · 人物台词卡（豆包用）

> **按人分，不按场景分。** 一个人 = 一份台词 = 一次音色选择 = 一段固定提示词。
> 这样 28 句配完，游戏里才听得出「谁在说话」；按场景配会把同一个人的声音在 7 场之间来回换。
>
> 台词与 `tools/gen_voice_tts.py` 的配音表逐字一致（单一来源）。**改台词 = 改剧情，不要手改。**
> 一共 **6 个人、28 句**。

---

## 一、怎么用（3 步，一个人做一遍）

1. 豆包里选**音色**（下面每张卡写了怎么挑），把【固定提示词】粘进风格/情绪/声音描述栏
2. 打开 `assets/audio_raw/_split/<代号>.txt`，**逐行生成**（一行一句，别整段一起生成）
3. 下载后按卡里的文件名存进
   `D:\Desktop\VibeCoding\godot_project\github_game_off_shift\shift\assets\audio_raw\tts\`

**先只做 W1 的第 1 句**（`a1_bang_0`「沈家赔了三十块洋钿。」），听 3 秒。不满意就换音色；
满意再把这个人的 6 句一次做完。别一次性做 28 句。

## 四、游戏里是这么交替播的（配完自查用）

每一场四句，甲、乙、甲、乙。你配的时候可以按这个顺序听一遍，确认「像两个人在对话」：

| 场景 | 播放顺序 |
|---|---|
| 1926 坝上·赔偿 | W1-1 → W2-1 → W1-2 → W2-2 |
| 1951 老井边·天灾 | W1-3 → W2-3 → W1-4 → W2-4 |
| 1976 田边·遗忘 | W1-5 → W2-5 → W1-6 → W2-6 |
| 1951 田边·激情案一 | M1-1 → M2-1 → M1-2 → M2-2 |
| 2001 工地外·迷信 | M1-3 → M2-3 → M1-4 → M2-4 |
| 2001 田边·激情案二 | M2-5 → M1-5 → M2-6 → M1-6 |
| 2026 路口·邪门 | W3-1 → M3-1 → W3-2 → M3-2 |

> 细节必须对得上：激情案两场里的「三号下午 / 姓王的先抡 / 判三年」「七号 / 李家老二 / 判七年」是全作唯一的「标准案子」标尺，念错就废。

## 六、你交回来之后我做

1. 统一加工：180Hz 高通 + 4kHz 低通（做出「隔了几十年」的质感）+ 短混响 + 空气底噪
2. **年代落差我本地做**：W1/W2 在 A2 降 12%、A3 降 18% —— 同一副嗓子往下沉，
   保证是「同一个人老了」而不是「换了三个演员」
3. 接到旁听系统（L20）

## 七、做不出来就告诉我卡在哪

没有提示词栏 / 音色列表挑不到老年男声 / 导出没有音频 / 字数限制 —— 说一声我改方案。
