# 旁听配音 · 台词卡（豆包用）

> 这份是**给你自己抄着用**的，不用交给任何会话。
> 台词与 `tools/gen_voice_tts.py` 的配音表逐字一致（单一来源），改台词 = 改剧情，别手改。
> 一共 **7 场戏、28 句**，每场两个人在说话。你要做的是：把「提示词 + 台词」粘进豆包，生成，下载，按文件名存。

---

## 一、怎么用（3 步）

1. 打开豆包 → 语音生成 / 朗读，先按卡里的**音色**挑一个中文声音
2. 把卡里的【提示词】粘进「风格 / 情绪 / 声音描述」那一栏，
   再把【台词】粘进正文，生成
3. 下载音频，**按卡里标的名字**存到
   `D:\Desktop\VibeCoding\godot_project\github_game_off_shift\shift\assets\audio_raw\tts\`
   （mp3 就行，别转 wav）

**先只做一句试听**：用 `a1_bang_0`「沈家赔了三十块洋钿。」 在豆包生成一次，听 3 秒。
满意再往下做；不满意换个音色重挑，别一次性做 28 句。

## 二、四个角色，对应四个声音

| 代号 | 谁 | 出现场景 | 挑音色的关键词 |
|---|---|---|---|
| **W1** | 女声 A | a1 / a2 / a3（同一人变老）、a5（本地老太太） | 年轻：清亮、普通话带一点江淮味；老年：沉、微哑 |
| **W2** | 女声 B | a1 / a2 / a3（另一人变老） | 比 W1 稍低稍厚，同样是农妇 |
| **M1** | 男声 A | a2_field、a4_site、a4_field、a5_road | 中年农村男声，粗一点、不播音腔 |
| **M2** | 男声 B | a2_field、a4_field、a4_site | 比 M1 更沉，说话更慢 |

> **关键设定**：W1/W2 在 1926 → 1951 → 1976 是**同一个人在变老**（25 年一级）。
> 所以三个年代尽量用**同一个音色**，只把语气从「亮」调到「沉」再调到「干」；
> 音高语速的年代落差我在本地统一处理（ffmpeg），你只要保证是同一个人。
> 2001 / 2026 换的是另一批人，声音要明显不同。

## 三、七张场景卡

### 卡 1 · `a1_bang` — 1926 · 坝上（赔偿）
**场景**：两个年轻农妇在坝上说话，说的是陆家后生没了、沈家赔了三十块洋钿。语气是闲聊、不是悲痛。

**W1（女声 A，二十出头，声音亮、语速偏快）**

- 提示词：`二十出头的年轻农妇，安徽农村口音，语气平静，像在田埂上跟邻家嫂子聊事，语速偏快，声音亮`
- `a1_bang_0` → 「沈家赔了三十块洋钿。」
- `a1_bang_2` → 「仁至义尽。陆家也认了。」（语气下结论，笃定一点）

**W2（女声 B，二十出头，声音比甲稍厚稍低）**

- 提示词：`二十出头的年轻农妇，声音比对方厚一点、低一点，问句带一点吃惊，语速正常`
- `a1_bang_1` → 「三十块？不少了。」
- `a1_bang_3` → 「认了就好。这年头，肯赔钱的主儿不多。」（放松下来，带感慨）

---

### 卡 2 · `a2_well` — 1951 · 老井边（天灾）
**场景**：同一批人，老了 25 年。同一件事已经被说成「民国十五年那场大水」。

**W1（四十五六岁，声音比年轻时沉，语速慢，带回忆的迟疑）**

- 提示词：`四十五六岁的中年农妇，同一个人的中年版，声音比年轻时沉，语速慢，带回忆时的迟疑`
- `a2_well_0` → 「民国十五年那场大水，你还记得？」
- `a2_well_2` → 「听说就是那么没的。」

**W2（四十五六岁，嗓子有点哑，说话干脆）**

- 提示词：`四十五六岁的中年农妇，嗓子有点哑，说话干脆但慢，不带感情`
- `a2_well_1` → 「记得。冲走了陆家一个后生。」
- `a2_well_3` → 「可不就是。水嘛，说来就来。」

---

### 卡 3 · `a3_field` — 1976 · 田边（遗忘）
**场景**：又老 25 年，七十上下。这件事已经变成「老辈子的事，谁还记得」。

**W1（七十上下，声音干、语速很慢、不耐烦）**

- 提示词：`七十岁上下的老年农妇，声音干、略微沙哑，语速很慢，语气不耐烦，像在田里说话`
- `a3_field_0` → 「老辈子的事，谁还记得。」
- `a3_field_2` → 「提什么提。地里的活还没干完。」

**W2（同龄，声音轻、有点含糊，像在低头干活）**

- 提示词：`七十岁上下的老年农妇，声音轻、有点含糊，像一边低头干活一边说话`
- `a3_field_1` → 「我阿爸提过一句，说陆家……」（尾音要断掉）
- `a3_field_3` → 「也是。」（很短，叹一口气那种）

### 卡 4 · `a2_field` — 1951 · 田边（激情案一）
**场景**：两个男人讲西头两户为地界打起来。**细节必须全对**：三号下午、姓王的先抡的、判三年。

**M1（三十多岁农村男人，嗓子粗，平铺直叙）**

- 提示词：`三十多岁的农村男人，嗓子粗，语气平平地在讲一件旧事，不做戏`
- `a2_field_0` → 「西头两户为地界打起来了。」
- `a2_field_2` → 「动了。三号下午，姓王的先抡的。」

**M2（同龄，声音更沉，追问时带好奇）**

- 提示词：`三十多岁的农村男人，声音更沉一点，追问时带一点好奇，语速慢`
- `a2_field_1` → 「动锄头了？判了几年？」
- `a2_field_3` → 「判了三年，当场就判了，人证物证都在。」

### 卡 5 · `a4_site` — 2001 · 超市工地外（迷信）
**场景**：两个工地男人压低声音说地基底下有东西。

**M1（四十多岁工地男人，压低声音，怕人听见）**

- 提示词：`四十多岁的工地男人，压低声音说话，像怕被人听见，语速偏慢`
- `a4_site_0` → 「这地基底下好像有东西。」
- `a4_site_2` → 「老人都这么说。挖的时候别往西边深了。」

**M2（同龄工人，语气直接、不耐烦）**

- 提示词：`四十多岁的工人，语气直接，有点不耐烦，不压声音`
- `a4_site_1` → 「什么东西？」
- `a4_site_3` → 「那就别挖了呗。」

**场景**：邻村为水渠打人。**细节必须全对**：七号那天、李家老二动的手、判七年。

## 五、你交回来之后我做什么

1. 统一加工：180Hz 高通 + 4kHz 低通（做出「隔了几十年听不清」的质感）+ 短混响 + 确定性空气底噪
   → 输出到 `assets/audio/voice/`，22050Hz mono 16bit
2. **年代落差我在本地统一做**：A2 降 12%、A3 降 18%（同一副嗓子往下沉），
   这样三个人声听起来还是「同一个人老了」，而不是「换了三个演员」
3. 28 句接到旁听系统里（L20 那条线）
